# Casos de Uso DICEVA

## 1. ConsultarComentariosJuegoMesaP

**Descripción:**  
Permite consultar los comentarios y valoraciones asociados a un juego de mesa.

**Actor principal:**  
Cliente

**Repositorio requerido:**  
ComentarioRepository

**Estado:**  
Documentado — pendiente de implementación

**Repositorio requerido:**

**Estado:**  
Documentado — pendiente de implementación
