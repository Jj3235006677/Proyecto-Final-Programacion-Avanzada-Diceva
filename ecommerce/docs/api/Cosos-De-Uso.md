# Casos de Uso DICEVA

## 1. Realizar compra

**Descripción:**  
Permite al cliente realizar la compra de uno o varios juegos de mesa.

**Actor principal:**  
Cliente

**Repositorio requerido:**  
CompraRepository

**Estado:**  
Implementado

---

## 2. Crear juego de mesa

**Descripción:**  
Permite al proveedor registrar un nuevo juego de mesa en el sistema.

**Actor principal:**  
Proveedor

**Repositorio requerido:**  
JuegoMesaRepository

**Estado:**  
Implementado

---

## 3. Realizar comentario

**Descripción:**  
Permite al cliente registrar una valoración y comentario sobre un juego de mesa.

**Actor principal:**  
Cliente

**Repositorio requerido:**  
ComentarioRepository

**Estado:**  
Implementado

---

## 4. Gestionar inventario de juegos de mesa

**Descripción:**

**Actor principal:**

**Repositorio requerido:**
