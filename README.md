# Proyecto-Final-Programacion-avanzada


Taller pruebas avanzadas 


Parte 0: En la parte cero estamos probando cómo nuestros repositorios consultan los datos y verificando que lo hagan bien, aplicando las tres AAA (Arrange, Act, Assert) en el orden visto en clase, para determinar que nuestros repositorios cumplan con la funcionalidad requerida. También comprendimos que, al usar @SpringBootTest, se carga nuestro archivo data.sql, y así evitamos crear todo desde casi cero


Parte 1: *Parte 1:** En la parte uno estamos probando la implementación de JWT en un endpoint determinado. Con esto verificamos que determinadas funciones del backend estén restringidas para los diferentes tipos de usuarios, logrando así las respuestas 401, 403 y 200. Lo que más me costó entender fue que el código 401 significa que no saben quién eres, el 403 significa que saben quién eres, pero no tienes permiso, y el 200 indica que la petición fue exitosa y que el endpoint realizó la función correctamente.
